# SQL Studio

Интерактивный курс SQL на русском языке. Для локального запуска нужен Python 3.11 или новее; сторонние пакеты не требуются.

```powershell
python server.py
```

Откройте http://127.0.0.1:8000. Порт можно задать переменной окружения `PORT`.

Для размещения на сервере предусмотрен `Dockerfile`. Подключите постоянный том к `/data`, иначе аккаунты и прогресс пропадут после пересоздания контейнера. Задайте `PUBLIC_URL` равным публичному HTTPS-адресу сайта; он используется в ссылках восстановления пароля и для защищённого cookie.

## Возможности

- 15 последовательных уровней, 100 заданий, теория и исполняемые примеры.
- Проверка результата SQL, а для некоторых финальных задач также проверка изучаемой конструкции.
- Учебная база SQLite в памяти, изолирована: запись разрешена в специальных заданиях; запросы ограничены по времени, длине и числу строк.
- Аккаунты, прогресс, опыт и достижения хранятся в `progress.sqlite3`.
- Подсказки, решение, объяснение ошибок и предварительный просмотр учебных таблиц.

Для отправки ссылок восстановления пароля задайте `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD` и `SMTP_FROM`. Для публичного размещения используйте HTTPS, постоянный том для базы прогресса и `PUBLIC_URL`. Сессии хранятся в памяти процесса: после перезапуска сервера нужно войти снова.

Контент расположен в `content.py` и `curriculum_extra.py`: новый уровень можно добавить без изменения интерфейса и правил навигации.

Проверка:

```powershell
python -m unittest -v test_app.py
node --check app.js
```
