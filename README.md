# SQL Studio

Интерактивный курс SQL на русском языке. Для локального запуска нужен Python 3.11 или новее; сторонние пакеты не требуются.

```powershell
python server.py
```

Откройте http://127.0.0.1:8000. Порт можно задать переменной окружения `PORT`.

Для размещения на сервере предусмотрен `Dockerfile`. Подключите постоянный том к `/data`, иначе аккаунты и прогресс пропадут после пересоздания контейнера. Задайте `PUBLIC_URL` равным публичному HTTPS-адресу сайта; он используется в ссылках восстановления пароля и для защищённого cookie.

## Netlify

На Netlify проект работает без отдельного Python-сервера: интерфейс собирается в `public/`, API размещается в Netlify Functions, а аккаунты и прогресс сохраняются в Netlify Blobs. Подключите репозиторий к Netlify и оставьте настройки сборки из `netlify.toml`. Сборка устанавливает зависимости из `package-lock.json` и запускает `npm run build`. Папка `public/` содержит только файлы интерфейса.

Для восстановления пароля задайте `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD` и `SMTP_FROM` в переменных окружения Netlify. Без них остальные функции курса работают, а форма восстановления сообщает, что почта пока не настроена.

После изменения уроков запустите `python export_course.py` и добавьте обновлённый `netlify/lib/course-data.mjs` в коммит.

## Возможности

- 15 последовательных уровней, 100 заданий, теория и исполняемые примеры.
- Проверка результата SQL, а для некоторых финальных задач также проверка изучаемой конструкции.
- Учебная база SQLite в памяти, изолирована: запись разрешена в специальных заданиях; запросы ограничены по времени, длине и числу строк.
- Аккаунты и прогресс хранятся в `progress.sqlite3` при локальном запуске или в Netlify Blobs при публикации на Netlify.
- Подсказки, решение, объяснение ошибок и предварительный просмотр учебных таблиц.

Для отправки ссылок восстановления пароля задайте `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD` и `SMTP_FROM`. Для публичного размещения используйте HTTPS, постоянный том для базы прогресса и `PUBLIC_URL`. Сессии хранятся в памяти процесса: после перезапуска сервера нужно войти снова.

Задания и эталонные запросы находятся в `content.py` и `curriculum_extra.py`. Теория уровня находится в `lesson-guide.js`, а объяснения перед каждым заданием — в `task-lessons.js`. При изменении порядка или числа заданий обновите соответствующие объяснения и запустите `python export_course.py`; тест проверяет соответствие всех 100 заданий и прохождение их решений через API.

Проверка:

```powershell
python -m unittest -v test_app.py
node --check app.js
npm run test:netlify
```
